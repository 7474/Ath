# アーヴ語ナレッジ（検索用）

生成 AI に文法・辞書を**毎回すべて載せない**ための種データです。翻訳時はキーワード検索と（対応していれば）ツール呼び出しで、関連チャンクだけを引きます。

| ファイル | 内容 |
|---|---|
| `phonemes.json` | 本ウェブフォントのキー → 音素 / IPA（音声合成用） |
| `grammar.json` | 文法カード（概要・格・動詞・後置詞など） |
| `lexicon.json` | 公開情報に基づく種語彙。完全な辞書ではない |

追加するときは同じ JSON 形でエントリを足してください。ファン作成の大規模辞書を丸ごとコピペしないでください（著作権・分量の両方の理由）。

文法・語彙の要約は [Wikipedia「アーヴ語」](https://ja.wikipedia.org/wiki/%E3%82%A2%E3%83%BC%E3%83%B4%E8%AA%9E)（CC BY-SA）の公開記述に基づきます。
