アーヴ語と日本語・英語

日本語・英語とアーヴ語を、このページで翻訳します。

使い方

  1. 入力と出力の言語を選びます。「自動」のままでも構いません。
  2. 原文を入れて「翻訳」を押します（Ctrl+Enter でも可）。
  3. 「読み上げ」で音声、「コピー」で訳文のコピー、「例文」で試し訳です。アーヴ語を選んだ欄はアース文字で表示します。
  4. エンジンの既定はローカル辞書です。使える環境では「サーバエージェント」も出ます。ブラウザの生成AIを使うときは、右上の設定にベース URL と API キーを保存してから切り替えてください。
  5. ローカル辞書のとき「訳語をベクトル検索」を入れると、意味の近い辞書の語で訳します。
  6. 語釈や格変化は下の辞書検索、動詞の変化は活用表です。

辞書

語を検索すると語釈と格変化が出ます。

CSV / JSON を選ぶと、このブラウザだけに語彙が上乗せされます。消すときは「追加分を消す」です。

活用

動詞を入れると直説法・仮定法などの語形を出します。

サーバエージェント / OpenAI 互換（任意）

生成AIやサーバエージェントを使うときだけ設定します。未設定のままでもローカル辞書で翻訳できます。 ブラウザの生成AIは、ベース URL と API キーを入れて「保存」し、エンジンを「生成AI（ブラウザ）」にしてください。キーはこのブラウザにだけ残ります。 サーバエージェントは、使えるときだけエンジンの選択肢に出ます。別の翻訳サーバを使うときは、その翻訳 URL を「エージェント URL」に入れて保存します。 読み上げは、生成AIを選んでいて音声に対応していればそれを使い、なければブラウザの読み上げです。

アーヴ語およびアースは森岡浩之『星界シリーズ』の架空言語・文字です。本ツールは Wikipedia「アーヴ語」の文法解説（CC BY-SA）に基づく二次創作です。 公式の完全辞書は公開されていないため、訳は再構成であり誤りを含みます。 GitHub
