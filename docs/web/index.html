アーヴ語と日本語・英語

Wikipedia「アーヴ語」の文法と、ファンサイトの公開辞書を走査した語彙で動く規則ベース翻訳です。 ブラウザ内で完結します。出典はページ末尾のスペシャルサンクスを見てください。 辞書にない固有名詞は発音からアーヴ語ローマ字へ転記し、その旨を表示します。 任意で OpenAI API キーを使うと、同じ辞書を根拠にした生成翻訳と音声合成もできます。

辞書

語を検索すると語釈と格変化が出ます。

CSV/JSON を読むとこのブラウザにだけ上乗せされます。サイト全体への取り込みは python -m baronh ingest を使います。

活用

動詞を入れると直説法・仮定法などの語形を出します。

OpenAI API（任意）

キーは localStorage にだけ保存し、api.openai.com 以外には送りません。未設定ならローカル辞書のみで動きます。

アーヴ語およびアースは森岡浩之『星界シリーズ』の架空言語・文字です。本ツールは Wikipedia「アーヴ語」の文法解説（CC BY-SA）に基づく二次創作です。 公式の完全辞書は公開されていないため、訳は再構成であり誤りを含みます。 GitHub
