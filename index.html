Use via URL (no download)

jsDelivr serves files from this public GitHub repository automatically. No signup, application, npm publish, or config file is required. Link the stylesheet; fonts resolve relative to the CSS URL. 

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/7474/Ath@main/docs/aarth.css">

<style>
  .ath-text { font-family: 'Aarth', serif; }
</style>

Then wrap text in <span class="ath-text">…</span>. For production, replace @main with a commit SHA (branch URLs are cached about 12 hours). raw.githubusercontent.com is not suitable.

When the font files sit next to your page, use a relative path:

<link rel="stylesheet" href="./aarth.css">

<style>
  .ath-text { font-family: 'Aarth', serif; }
</style>

Use @font-face with font URLs

If you prefer to declare the face yourself:

@font-face {
  font-family: 'Aarth';
  src: url('./aarth.woff2') format('woff2'),
       url('./aarth.ttf')   format('truetype');
  font-weight: normal;
  font-style:  normal;
  font-display: swap;
}

.ath-text {
  font-family: 'Aarth', serif;
}

Use a local copy

For offline apps, copy aarth.woff2 (and optionally aarth.ttf) next to your CSS, then use the same @font-face with relative paths.

Character mapping: see the full table. Use standard lowercase a–z plus é ï œ ü ÿ for the special vowels, uppercase A I E for the digraphs ai, au, eu, and digits 0–9 when numerals are in the webfont.
