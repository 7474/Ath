How to use in your own project

Copy aarth.woff2 (and optionally aarth.ttf) next to your CSS file, then add:

@font-face {
  font-family: 'Aarth';
  src: url('aarth.woff2') format('woff2'),
       url('aarth.ttf')   format('truetype');
  font-weight: normal;
  font-style:  normal;
  font-display: swap;
}

.ath-text {
  font-family: 'Aarth', serif;
}

Then wrap any text in <span class="ath-text">…</span>.

Character mapping: use standard lowercase a–z plus é ï œ ü ÿ for the special vowels, and uppercase A I E for the digraphs ai, au, eu.
