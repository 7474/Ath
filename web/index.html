アーヴ語と日本語・英語

Wikipedia「アーヴ語」の文法と、ファンサイトの公開辞書を走査した語彙で動く規則ベース翻訳です。 ブラウザ内で完結します。出典はページ末尾のスペシャルサンクスを見てください。 辞書にない固有名詞は発音からアーヴ語ローマ字へ転記し、その旨を表示します。 任意で OpenAI 互換 API を指定すると、下訳と検索した辞書を渡して生成翻訳できます。音声合成は別呼び出しです。

生成AI / OpenAI 互換 API（任意）

キーとベース URL は localStorage にだけ保存し、指定したエンドポイントへだけ送ります。 既定は https://api.openai.com/v1 です。LM Studio / vLLM / LiteLLM / Ollama（OpenAI 互換）なども同じ形で指定できます。 未設定ならローカル辞書のみで動きます。辞書全文は送りません。関連語は辞書を全件スキャンして点数付けし、足りない語は lookup_lexicon / grammar_note で追加検索します。生成したアーヴ語は辞書の語形と照合し、造語なら書き直しを求めます。 音声合成は翻訳とは別の /audio/speech です。未対応の互換実装ではブラウザ読み上げに戻ります。

アーヴ語およびアースは森岡浩之『星界シリーズ』の架空言語・文字です。本ツールは Wikipedia「アーヴ語」の文法解説（CC BY-SA）に基づく二次創作です。 公式の完全辞書は公開されていないため、訳は再構成であり誤りを含みます。 GitHub
