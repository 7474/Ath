アーヴ語と日本語・英語

Wikipedia「アーヴ語」の文法と、ファンサイトの公開辞書を走査した語彙で動く規則ベース翻訳です。 出典はページ末尾のスペシャルサンクスを見てください。 辞書にない固有名詞は発音からアーヴ語ローマ字へ転記します。 サーバエージェントはベクトル検索した辞書と文法を生成 AI に渡し、類義語で意味を通します（python -m baronh serve または Cloud Run。生成 AI 必須）。 ブラウザから OpenAI 互換 API を直接呼ぶ経路は実験用です。

サーバエージェント / OpenAI 互換（任意）

サーバエージェントは辞書のベクトル検索・文法コンテキスト・ツール往復をサーバで行います。キーはサーバの環境変数に置き、ブラウザには出しません。生成 AI が無いと動きません。 既定の URL は同じオリジンの /api/translate です（python -m baronh serve）。 GitHub Pages から使うときは Cloud Run などの URL を入れてください。構成の比較はリポジトリの baronh/DEPLOY.md にあります。 ブラウザから Chat Completions を直接呼ぶ経路は実験用です。キーは localStorage にだけ保存します。

アーヴ語およびアースは森岡浩之『星界シリーズ』の架空言語・文字です。本ツールは Wikipedia「アーヴ語」の文法解説（CC BY-SA）に基づく二次創作です。 公式の完全辞書は公開されていないため、訳は再構成であり誤りを含みます。 GitHub
